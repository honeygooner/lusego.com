# lusego.com

## about

lusego is designed with privacy in mind: all user data, including collections and search history, is stored locally with no accounts or centralized backend required. the app pulls content directly from public image boards and presents it through a minimal and responsive interface. its goal is to make discovery intuitive and surface the incredible art already out there.

## getting started

```shell
npm install
npm run dev
```
